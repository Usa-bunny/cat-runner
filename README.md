# dino-runner

> The T-Rex runner game extracted from the Chrome offline error page.

See the official [source](https://cs.chromium.org/chromium/src/components/neterror/resources/offline.js?q=t-rex+package:%5Echromium$&dr=C&l=7) from Chromium.

---

## 🚀 Getting Started

### Installation
1. Clone the repository:
~~~bash
git clone https://github.com
cd dino-runner
~~~


2. Run
Just clicking index.html or use live server
